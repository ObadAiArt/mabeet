# تعهد ولي الأمر — موقع تعبئة وتوقيع إلكتروني

موقع بسيط يتيح لولي الأمر تعبئة تعهد المبيت/الاعتكاف والتوقيع بإصبعه، ثم تنزيل الملف PDF أو إرساله عبر واتساب. ويحفظ نسخة تلقائياً لدى المسؤول (اختياري).

## الروابط
- صفحة ولي الأمر: `index.html`
- لوحة المسؤول: `admin.html`

ولي الأمر يكتب اسمه واسم الطالب ورقمه ويوقّع فقط. أما المسجد واليوم والتاريخ فيحددها المسؤول من لوحة المسؤول قبل كل مبيت، وتظهر تلقائياً لولي الأمر.

## تفعيل الحفظ لدى المسؤول (5 دقائق، مرة واحدة)
1. افتح https://script.google.com واضغط **مشروع جديد**.
2. احذف المحتوى والصق محتوى الملف `apps-script/Code.gs`، وغيّر `ADMIN_KEY` إلى كلمة مرور من اختيارك.
3. اضغط **نشر ← نشر جديد ← نوع: تطبيق ويب**:
   - التنفيذ بصفتي: **أنا**
   - من يملك الوصول: **أي شخص** (Anyone)
4. اضغط نشر، ووافق على الأذونات، وانسخ **رابط تطبيق الويب**.
5. ضع الرابط في `config.js` في الحقل `SCRIPT_URL`، واحفظ وارفع التغيير إلى GitHub.

بعد ذلك: كل تعهد يُنشأ يُحفظ كصورة في مجلد `تعهدات الاعتكاف` في Google Drive الخاص بك، ويظهر في `admin.html` بعد إدخال كلمة المرور.

## قبل كل مبيت
افتح `admin.html`، أدخل كلمة المرور، عدّل المسجد واليوم والتاريخ واضغط حفظ، ثم أرسل رابط الموقع للأهالي.

## ملاحظة مهمة عند النشر
إذا ظهرت رسالة "الوصول مرفوض" أو لم تعمل لوحة المسؤول، فافتح **نشر ← إدارة عمليات النشر ← تعديل**، واختر "من يملك الوصول: **أي شخص**" (وليس "أي شخص لديه حساب Google")، ثم **إصدار جديد** ونشر. بعد كل تعديل على `Code.gs` يجب عمل إصدار جديد بنفس الطريقة.
