# تعهد ولي الأمر — تسليم إلكتروني

- **صفحة ولي الأمر** (`index.html`): يكتب اسمه واسم الطالب ورقمه ويوقّع بإصبعه ويضغط **تسليم**. انتهى.
- **لوحة المسؤول** (`admin.html`): تدخل بكلمة المرور، تكتب المسجد واليوم والتاريخ، تختار طلابك بعلامة ✓، وتضغط **تنزيل الملف** فيُنزَّل PDF واحد فيه صفحة تعهد لكل طالب.

## الإعداد (مرة واحدة)
1. افتح https://script.google.com ← مشروع جديد، والصق محتوى `apps-script/Code.gs`، وغيّر `ADMIN_KEY`.
2. نشر ← نشر جديد ← تطبيق ويب: التنفيذ بصفتي **أنا**، الوصول **أي شخص**. انسخ رابط تطبيق الويب.
3. ضعه في `config.js` في `SCRIPT_URL`.

## بعد أي تعديل على `Code.gs`
نشر ← إدارة عمليات النشر ← القلم ← الإصدار: **إصدار جديد** ← نشر. الرابط لا يتغير.
